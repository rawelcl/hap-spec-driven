# Documentacao para o Desenvolvedor — Framework Spec-Driven Hapvida

Pasta de documentacao orientada ao **usuario dev** que adota o framework.
Aqui ficam apresentacao, guia rapido, arquitetura e cheat sheets.

## Indice

| Arquivo | Conteudo |
|---|---|
| [apresentacao.md](apresentacao.md) | O que e, por que usar, como funciona em 5 minutos |
| [guia-rapido.md](guia-rapido.md) | Cheat sheet: comandos `/`, fluxo das fases, exemplos |
| [arquitetura.md](arquitetura.md) | Visao em camadas do framework, integracoes, guardrails |

## Onde mora o que

```
prompts/          <- comandos / no VS Code Chat (hap-sd-*)
templates/        <- templates de spec, design, tasks, ADR
references/       <- documentos de referencia das fases e praticas
adr/              <- decisoes arquiteturais do proprio framework
skills/           <- skills especializadas (RE PL/SQL, Forms)
glossario/        <- terminologia de dominio (Comercial, ANS, Legado)
```
