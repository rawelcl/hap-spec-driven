# Roadmap (do squad)

**Goal:** Visao de medio prazo do squad - milestones, features no horizonte.

**Output:** `.specs/project/ROADMAP.md`

**Opcional** - muitos squads usam Epic + ADO Boards nativos como roadmap. ROADMAP.md e util quando:
- Squad quer narrativa em prosa, nao so lista de Epics
- Squad mantem visao de longo prazo separada da execucao tatica do board

## Estrutura

```markdown
# Roadmap

**Current Milestone:** [Nome] - [status]
**Target:** [data]

---

## v[N] - [Milestone Title]

**Goal:** [O que sera entregue]

### Features

**[Feature 1]** - [STATUS]
- [Bullet curto]
- [Bullet curto]

**[Feature 2]** - [STATUS]
- [Bullet curto]

**[Feature 3]** - [STATUS]
- [Bullet curto]

---

## v[N+1] - [Milestone Title]

**Goal:** [O que sera entregue]

### Features
[mesma estrutura]

---

## Future Considerations

- [Idea 1]
- [Idea 2]
```

## Adaptacoes Hapvida

- Cada feature do roadmap deve mapear para um Epic ou Feature no ADO
- Quando feature do roadmap entra em execucao, link para o work item ADO
